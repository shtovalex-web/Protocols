# Сравнение трудоёмкости формирования протоколов проверки знаний

**Документ:** оценка трудозатрат при ручном оформлении и при использовании программы **ProtocolOOT**  
**Дата:** июль 2026  
**Пример расчёта:** 1 сотрудник, 14 программ обучения в таблице результатов протокола

---

## 1. Условия примера

| Параметр | Значение |
|----------|----------|
| Объект | 1 сотрудник, 1 протокол проверки знаний |
| Программы | **14 строк** в таблице результатов (типично: Б + ПП + СИЗ + 11 программ блока «В» по должности) |
| Ручной способ | Word-шаблон вручную + заполнение XSD-шаблона / портала Минтруда + прописка № реестра шариковой ручкой |
| С программой | **ProtocolOOT** (загрузка из Excel, автозаполнение DOCX/PDF, выгрузка .xlsx + .xml, подстановка номеров из реестра) |

Нормы времени приведены для **опытного** специалиста по охране труда при уже подготовленных шаблонах и базах Excel. Диапазон «мин–макс» отражает разброс при поиске текстов программ и сверке с реестром.

**Важно:** цифры — экспертная оценка для обоснования. Для точного расчёта в организации рекомендуется хронометраж 2–3 протоколов в каждом режиме.

---

## 2. Ручной способ (без программы)

### 2.1. Этап А. Формирование протокола в Word

| Шаг | Операции | Время |
|-----|----------|-------|
| 1 | Найти сотрудника в Excel, сверить ФИО, должность, подразделение, СНИЛС | 2–3 мин |
| 2 | Открыть шаблон Word, ввести дату, № протокола, вид проверки | 3–5 мин |
| 3 | Внести состав комиссии, подписи (поиск в приказе / Excel) | 5–8 мин |
| 4 | **По каждой из 14 программ:** найти текст на листах B / V_PROF / PP / SIZ / V, сверить ID, вписать в строку таблицы | **4–6 мин × 14 = 56–84 мин** |
| 5 | Проверка орфографии, нумерации, выравнивание таблицы | 8–12 мин |
| 6 | Сохранение, печать | 2–3 мин |
| **Итого этап А** | | **76–115 мин (1,3–1,9 ч)** |

**Типичные риски:** ошибки в наименованиях программ, неверная нумерация блока «В», несоответствие должности тексту из V_PROF.

### 2.2. Этап Б. Внесение данных на сайт Минтруда (через XSD-шаблон)

| Шаг | Операции | Время |
|-----|----------|-------|
| 1 | Открыть официальный «Шаблон_Минтруд_XSD_УМН.xlsx», ввести реквизиты работодателя | 5–8 мин |
| 2 | **По каждой из 14 строк:** ФИО, СНИЛС, должность, дата, № протокола, ID программы (поиск на листе V), результат | **4–6 мин × 14 = 56–84 мин** |
| 3 | Проверка формата дат, СНИЛС, дублей | 10–15 мин |
| 4 | Сохранение, загрузка на портал АКОТ / Минтруда, ожидание обработки | 10–20 мин |
| **Итого этап Б** | | **81–127 мин (1,4–2,1 ч)** |

**Типичные риски:** неверный ID программы, расхождение должности между протоколом и шаблоном, отклонение файла порталом и повторное заполнение.

### 2.3. Этап В. Прописка номеров реестра шариковой ручкой

После регистрации на портале скачивается файл «Реестр обученных…».

| Шаг | Операции | Время |
|-----|----------|-------|
| 1 | Скачать реестр, открыть рядом с печатным протоколом | 3–5 мин |
| 2 | **По каждой из 14 строк:** найти запись (ФИО / СНИЛС / программа / № протокола), сверить, аккуратно вписать № ручкой | **3–5 мин × 14 = 42–70 мин** |
| 3 | Повторная сверка, исправление ошибочных цифр | 5–15 мин |
| **Итого этап В** | | **50–90 мин (0,8–1,5 ч)** |

**Типичные риски:** нечитаемый почерк, перепутанные номера при одном ФИО и нескольких программах, необходимость перепечатки.

### 2.4. Суммарно — ручной способ (1 сотрудник, 14 программ)

| Этап | Минимум | Максимум |
|------|---------|----------|
| А. Протокол Word | 76 мин | 115 мин |
| Б. Шаблон Минтруда | 81 мин | 127 мин |
| В. Прописка № реестра | 50 мин | 90 мин |
| **ВСЕГО** | **~207 мин (~3,5 ч)** | **~332 мин (~5,5 ч)** |
| **Средняя оценка** | | **~270 мин (~4,5 ч)** |

## 3. С использованием программы ProtocolOOT

### 3.1. Этап А. Формирование протокола

| Шаг | Операции | Время |
|-----|----------|-------|
| 1 | Выбор сотрудника в списке (данные из Data_base.xlsx) | 0,5 мин |
| 2 | Отметка программ Б / ПП / СИЗ / В — тексты подтягиваются из кэша листов | 1–2 мин |
| 3 | Дата, № протокола (автоинкремент), оценка, вид проверки | 0,5 мин |
| 4 | «Сформировать протокол» → предпросмотр → «Сохранить DOCX/PDF» | 1–2 мин |
| **Итого этап А** | | **3–5 мин** |

**Автоматизируется:** таблица на 14 строк, тексты программ, блоки Б / ПП / СИЗ / В, родительный падеж ФИО комиссии, формат № протокола.

### 3.2. Этап Б. Выгрузка для Минтруда

| Шаг | Операции | Время |
|-----|----------|-------|
| 1 | Запись уже в журнале protocols.db при сохранении | 0 мин (автоматически) |
| 2 | «Минтруд» → «Шаблон для загрузки на сайт…» — выбор записи, сохранение .xlsx + .xml | 2–4 мин |
| 3 | Загрузка файла на портал (вручную) | 5–10 мин |
| **Итого этап Б** | | **7–14 мин** |

**Автоматизируется:** 14 строк XSD-шаблона, ID программ с листа V, СНИЛС из Excel, должность (для «В» — из протокола), формирование XML.

### 3.3. Этап В. Номера реестра (без ручной прописки)

| Шаг | Операции | Время |
|-----|----------|-------|
| 1 | Скачать реестр с портала, указать файл в программе | 2–3 мин |
| 2 | «Минтруд» → «Пересформировать протокол (номера реестра)…» | 0,5–1 мин |
| 3 | Сохранить DOCX / PDF с подставленными № | 1 мин |
| **Итого этап В** | | **3,5–5 мин** |

**Автоматизируется:** сопоставление по СНИЛС / ФИО / № протокола / программе; прописка ручкой не требуется.

### 3.4. Суммарно — с программой (1 сотрудник, 14 программ)

|------|---------|----------|

| В. Номера реестра | 3,5 мин | 5 мин |
| **ВСЕГО** | **~13,5 мин** | **~24 мин** |

## 4. Сокращение трудозатрат (пример на 14 программах)

| Показатель | Ручной способ | С программой | Экономия |
|------------|---------------|--------------|----------|
| Время на 1 протокол (14 программ) | ~270 мин (~4,5 ч) | ~18 мин | **~252 мин (~4,2 ч)** |
| Доля сокращения | 100% | **~7%** от ручного | **~93%** |
| Операций ручного ввода (оценка) | ~42–56 | ~5–8 | **~85–90%** |

### Масштабирование на партию сотрудников

| Сценарий | Ручной способ | С программой | Экономия |
|----------|---------------|--------------|----------|
| **10 сотрудников** × 14 программ | ~45 ч | ~3–4 ч* | **~41 ч (~91%)** |
| **30 сотрудников** × 14 программ | ~135 ч | ~6–8 ч* | **~127 ч (~94%)** |

\* При пакетной выгрузке Минтруда из журнала и использовании функции «По одному на каждого → в папку…» время на одного человека снижается: общая выгрузка XSD и однократное подключение реестра распределяются на всю партию.

## 5. Что именно сокращает программа

**Ручной способ (цепочка операций):**

1. Поиск текстов 14 программ в Excel.
2. Ручной ввод в Word.
3. 14 строк в XSD-шаблоне Минтруда.
4. Загрузка на портал.
5. 14 номеров реестра — прописка ручкой в бумажный протокол.

**С программой ProtocolOOT (цепочка операций):**

1. Выбор сотрудника и отметка программ.
2. Автозаполнение DOCX.
3. Журнал → выгрузка XSD + XML.
4. Загрузка на портал (вручную).
5. Подключение реестра → автоподстановка № в протокол.

| Операция | Ручной способ | Программа |
|----------|---------------|-----------|
| Тексты 14 программ в протокол | Копирование из 4–5 листов Excel | Автоматически из кэша B / V_PROF / PP / SIZ / V |
| ID программ для Минтруда | Ручной поиск на листе V | Автосопоставление |
| 14 строк XSD-шаблона | Ручной ввод каждого поля | Из журнала одной операцией |
| № реестра в протокол | Шариковая ручка, сверка | «Пересформировать протокол» |
| Журнал учёта | Отдельная таблица / тетрадь | protocols.db |
| Риск ошибки при 14 программах | Высокий | Низкий (сверка в предпросмотре) |

**Не автоматизируется программой:** первичная подготовка Excel-баз, загрузка файла на портал Минтруда, ожидание регистрации на портале, печать и подписи на бумаге.

---

## 6. Оговорки для отчёта и обоснования

1. **14 программ** в расчёте — это 14 строк в таблице результатов одного протокола. Если требуется 14 **отдельных** протоколов (по одной программе), умножьте расчёт на 14.
2. Нормы времени — **экспертная оценка**, не замеры в конкретной организации.
3. Экономия **максимальна** при регулярных проверках и заранее заполненных Data_base.xlsx / Programs_base.xlsx.
4. Требования портала Минтруда / АКОТ и формата XSD могут меняться — загрузка на сайт остаётся ручным шагом в обоих сценариях.

---

## 7. Краткий вывод для руководства

При формировании **одного протокола на 14 программ** полный ручной цикл (Word + XSD Минтруда + прописка № реестра ручкой) занимает в среднем **около 4–5 часов** на одного сотрудника.

С **ProtocolOOT** тот же цикл занимает **около 15–25 минут**.

**Сокращение трудозатрат — порядка 90–95%** (экономия **около 4 часов** на один такой протокол).

На партии из **10 человек** экономия составляет порядка **40+ человеко-часов** только на оформлении документов, без учёта снижения ошибок и повторной работы.
